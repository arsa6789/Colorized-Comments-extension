# Colorized Comments 彩色注释扩展

[English](./README.md) | 中文

为 VS Code 打造的代码注释美化扩展。通过自定义背景色和文字颜色，让重要的注释更加醒目，提升代码的可读性。

![演示](https://i.imgur.com/OIfZQUq.gif)

## 特性

- 🎨 预设精选配色方案，快速应用
- 🔄 完全自定义的背景色和文字颜色
- 💾 设置自动保存，重启 VS Code 后保持
- 🌍 支持超过 30 种主流编程语言
- ⚡ 支持悬停和右键菜单快速操作

## 使用方法

### 通过鼠标悬停

1. 将鼠标悬停在注释行上
2. 等待 3 秒（可自定义时长）
3. 选择修改背景色或文字颜色
4. 选择喜欢的颜色

### 通过右键菜单

1. 在注释行右键点击
2. 选择"Change Comment Style"
3. 按提示操作

## 扩展设置

| 配置项                         | 说明                     | 默认值 |
| ------------------------------ | ------------------------ | ------ |
| `colorizedComments.hoverDelay` | 悬停多久后显示颜色选择器 | 3000ms |

## 支持的语言

- JavaScript/TypeScript
- Python, Java, C/C++
- HTML, CSS, PHP
- 以及超过 25 种其他语言
